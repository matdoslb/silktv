# silkTV.

A personal tvOS media player, currently under development and tested on home devices.

SilkTV is a private project exploring a clean Apple TV interface for live television, movies and series from user-configured media sources. Development focuses on smooth playback, deinterlacing, programme guides and an easy-to-browse personal library.

## Current status

- Personal, non-commercial home use and testing.
- No public app release, App Store listing or downloadable build.
- No subscriptions, advertising or revenue at this stage.

This public repository is the project's information page. It does not contain the application source code, credentials, playlists or media files.

## Movie and series artwork

A metadata and artwork integration is being evaluated for personal testing. The intended TMDB API usage is to look up movie and TV-series titles, descriptions, posters, background images and title logos for display in the app and its local artwork editor.

The integration is under development. SilkTV is not endorsed or certified by TMDB. Any future use beyond the current personal, non-commercial scope would require reviewing the applicable terms and obtaining any necessary approval.

## Media sources

SilkTV is a player, not a content service. It does not supply, sell or distribute television channels, subscriptions, films or series. Media must come from sources the user is authorised to access.
